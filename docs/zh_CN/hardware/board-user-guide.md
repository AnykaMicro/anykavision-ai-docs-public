# 产品板使用指南

## 文档简介

本文档以AI拍摄眼镜产品板为实例，介绍产品板的相关技术参数，以及产品板硬件设计过程中的参考资料。本文档面向硬件工程师与方案选型人员，用于快速了解产品板技术参数并获取设计参考。
## 产品板信息

AI拍摄眼镜产品板是一款基于KM02G系列芯片和AK1090系列芯片主控芯片的产品板。开发者可以基于此产品板进行AI智能拍摄眼镜的原型设计。KM02G系列芯片与AK1090系列芯片相关信息请参考[KM02G系列芯片介绍](chips/km02g.md)和[AK1090系列芯片介绍](chips/ak1090.md)。

## 产品板技术参数

| **类别** | **参数描述**                                  |
| ------ | ----------------------------------------- |
| 主控平台   | 产品板基于Anyka的芯片KM02G系列芯片+AK1090系列芯片 |
| 存储     | 4GiB SD Nand Flash、16MiB SPI NOR Flash    |
| 连接     | Wi-Fi（2.4G/5G,高拓WiFi芯片ATBM6162）+AK1090系列芯片        |
| 影像     | 支持13MP CIS模组 GC13B0                       |
| 音频     | 1个开放式扬声器+3个硅麦（1个AMIC、2个DMIC）              |
| 充电     | Type-C充电接口，最大充电电流180mA                    |

## 应用程序开发

本节主要介绍硬件和软件的设置方法，以及烧录固件至产品板，以及开发应用程序的说明。

### 硬件准备

- 1 x KM02G系列芯片+AK1090系列芯片产品板
- 1 x USB 2.0数据线（标准A型转Type-C型）
- 1 x 电脑（Windows、Linux系统）
- 1 x 手机（Android系统，用于 Anyka_Glasses APP；该 APP 尚未发布，可由开发者在后续版本中补充）

### 连接与烧录

用 USB 2.0 数据线连接产品板的 Type-C 接口和电脑，然后按[固件烧写](../software/board/firmware-flashing.md)升级固件。

更多详细配置请参考[应用开发说明](../software/board/app-development.md)。
