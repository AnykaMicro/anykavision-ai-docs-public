# 视频输入

## 概述

&emsp;&emsp;其中视频输入模块（VI模块）主要负责采集视频数据，并送往VPSS模块处理。

| **芯片简称**    | **ISP功能支持** |
| ----------- | ----------- |
| KM02G系列芯片 | 支持          |

<br/>

## API参考

&emsp;&emsp;本模块提供API参考，如下表所示：

| **数据结构**        | **描述**   |
| --------------- | -------- |
| VI_INTF_MODE_E  | VI输入接口类型 |
| VI_CHN_MODE_E   | VI通道工作模式 |
| VI_DEV_ATTR_S   | VI设备属性   |
| VI_CHN_ATTR_S   | VI通道属性   |
| VI_RECTANGLE_S  | 视频分辨率    |
| VI_FRAME_INFO_S | 帧结构体     |

<br/>

| **函数接口**               | **描述**         |
| ---------------------- | -------------- |
| AK_MPI_VI_GetVersion   | 获取视频输入库的版本号    |
| AK_MPI_VI_CreateDev    | 创建VI设备         |
| AK_MPI_VI_DestroyDev   | 销毁VI设备         |
| AK_MPI_VI_SetDevAttr   | 设置VI设备属性       |
| AK_MPI_VI_GetDevAttr   | 获取VI设备属性       |
| AK_MPI_VI_SetChnAttr   | 设置VI通道属性       |
| AK_MPI_VI_GetChnAttr   | 获取VI通道属性       |
| AK_MPI_VI_EnableDev    | 使能VI设备         |
| AK_MPI_VI_DisableDev   | 禁用VI设备         |

| AK_MPI_VI_DisableChn   | 禁用VI通道         |

## 数据结构

### VI_INTF_MODE_E

&emsp;&emsp;【说明】

&emsp;&emsp;VI输入接口类型

&emsp;&emsp;【定义】

```c
typedef enum akVI_INTF_MODE_E {
    VI_INTF_DVP = 0,                 //DVP Parallel interface
    VI_INTF_MIPI_1,                     //MIPI Serial Single-Line Interface.
    VI_INTF_MIPI_2,                     //MIPI Serial Two-Line Interface.
    VI_INTF_MULTI_DVP,               //Multiple camera DVP interface.
    VI_INTF_MULTI_MIPI_1,            //Multiple camera MIPI Single-Line Interface.
    VI_INTF_MULTI_MIPI_2,            //Multiple camera MIPI Two-Line Interface.
    VI_INTF_TOTAL
}VI_INTF_MODE_E;
```

&emsp;&emsp;【成员】

| **成员名称**             | **描述**               |
| -------------------- | -------------------- |
| VI_INTF_DVP          | DVP并行接口              |
| VI_INTF_MIPI_1       | MIPI串行1线接口           |
| VI_INTF_MIPI_2       | MIPI串行2线接口           |
| VI_INTF_MULTI_DVP    | 多目模式DVP接口（暂不支持，保留设计） |
| VI_INTF_MULTI_MIPI_1 | 多目模式MIPI 1线接口        |
| VI_INTF_MULTI_MIPI_2 | 多目模式MIPI 2线接口        |
| VI_INTF_TOTAL        | 类型总数                 |

&emsp;&emsp;【相关函数接口】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

<br/>

### VI_CHN_MODE_E

&emsp;&emsp;【说明】

&emsp;&emsp;VI通道工作模式。

&emsp;&emsp;【定义】

```c
typedef enum akVI_CHN_MODE_E
{
    VI_CHN_MODE_USER,
    VI_CHN_MODE_AUTO,
    VI_CHN_MODE_TOTAL
}VI_CHN_MODE_E;
```

&emsp;&emsp;【成员】

| **成员名称**          | **描述** |
| ----------------- | ------ |
| VI_CHN_MODE_USER  | User模式 |
| VI_CHN_MODE_AUTO  | Auto模式 |
| VI_CHN_MODE_TOTAL | 模式总数   |

&emsp;&emsp;【相关函数接口】

```c
AK_S32 AK_MPI_VI_SetChnAttr(AK_S32 s32DevId, AK_S32 s32ChnId, const VI_CHN_ATTR_S *pstViChnAttr);
```

> 说明：User模式下将为用户层获取帧分配内存，此时AK_MPI_VI_GetFrame才有数据输出。Auto模式则不会为用户层获取帧数据提供额外内存，两种模式都适合绑定VPSS，只是user模式会额外申请内存存放供应用层获取的视频帧图像数据。

### VI_DEV_ATTR_S

&emsp;&emsp;【说明】

&emsp;&emsp;VI设备属性。支持裁剪

&emsp;&emsp;【定义】

```c
typedef struct akVI_DEV_ATTR_S
{
    AK_U32                u32Width;           //vi dev width
    AK_U32                u32Height;          //vi dev height
    CROP_INFO_S            stCropInfo;         //vi crop info
    VI_INTF_MODE_E        enIntfMode;         //vi interface mode
    PIXEL_FORMAT_E         enInputPixFmt;      //vi dev input pixel formate
    AK_U32                 u32Fps;             //sensor input fps
    AK_BOOL                bMirror;            //if mirror
    AK_BOOL                bFlip;              //if flip
}VI_DEV_ATTR_S;
```

&emsp;&emsp;【成员】

| **成员名称**      | **描述**           |
| ------------- | ---------------- |
| u32Width      | VI设备端输入的宽度。      |
| u32Height     | VI设备端输入的高度。      |
| stCropInfo    | 分辨率信息。           |
| enIntfMode    | VI设备接口类型。        |
| enInputPixFmt | sensor输入的数据像素格式。 |
| u32Fps        | Sensor端输入帧率。     |
| bMirror       | 是否水平翻转。          |
| bFlip         | 是否垂直翻转。          |

&emsp;&emsp;【相关函数接口】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

<br/>

### VI_CHN_ATTR_S

&emsp;&emsp;【说明】

&emsp;&emsp;VI通道属性。支持缩小操作，不支持放大。通过输出分辨率与设备的分辨率比例定缩小比例

&emsp;&emsp;【定义】

```c
typedef struct akVI_CHN_ATTR_S
{
    AK_U32                u32Width;           //vi chn width
    AK_U32                u32Height;          //vi chn height
    AK_U32                u32MaxPerFrameSize; //vi chn buffer size
    PIXEL_FORMAT_E         enOutputPixFmt;     //vi chn ouput pixel formate
    AK_U32                 u32Fps;             //vi chn output fps
    AK_U32                u32FrameDepth;      //vi chn frame depth
    VI_CHN_MODE_E        enMode;             //vi chn mode
}VI_CHN_ATTR_S;
```

&emsp;&emsp;【成员】

| **成员名称**           | **描述**                         |
| ------------------ | ------------------------------ |
| u32Width           | VI CHN输出宽度及裁剪宽度。               |
| u32Height          | VI CHN输出高度及裁剪高度。               |
| u32MaxPerFrameSize | 单帧最大缓存大小，单位KB，为0时使用默认大小;       |
| enOutputPixFmt     | VI CHN输出的数据像素格式。               |
| u32Fps             | VI CHN输出的帧率。                   |
| u32FrameDepth      | 内部缓存帧数，与u32MaxPerFrameSize配合使用 |
| enMode             | 通道工作模式。                        |

&emsp;&emsp;【相关函数接口】

```c
    AK_S32 AK_MPI_VI_SetChnAttr(AK_S32 s32DevId, AK_S32 s32ChnId,
                                    const VI_CHN_ATTR_S *pstViChnAttr);
```

## 接口

### **AK_MPI_VI_CreateDev**

&emsp;&emsp;【描述】

&emsp;&emsp;创建VI设备。创建多个时为分时复用VI 硬件。

&emsp;&emsp;【语法】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

&emsp;&emsp;【参数】

| **参数名称**     | **描述**    | 取值范围  | **输入/输出** |
| ------------ | --------- | ----- | --------- |
| s32DevId     | 设备id      | [0-3] | 输入        |
| pstViDevAttr | vi设备属性结构体 | -     | 输入        |

&emsp;&emsp;【返回值】

| **返回值** | **描述**    |
| ------- | --------- |
| 0       | 成功        |
| 非0      | 失败，其值为错误码 |

&emsp;&emsp;【错误码列表】

| **错误码**                | **描述** |
| ---------------------- | ------ |
| ERROR_VI_INVALID_DEVID | 设备号不支持 |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_vi.so

&emsp;&emsp;头文件：ak_vi.h

> 注意：VI模块应当首先调用AK_MPI_VI_CreateDev接口

<br/>

### AK_MPI_VI_SetDevAttr

&emsp;&emsp;【描述】

&emsp;&emsp;设置VI设备属性包括帧率控制，裁剪信息等。如果是多目模式的话，VI在创建设备的时候需要传入多路MIPI的接口类型，即在第二个DEV设置属性时如果不是多目模式，将会报错处理。

&emsp;&emsp;【语法】


| ------------ | -------- | --------------- | --------- |
| s32DevId     | 设备id     | [0-3]           | 输入        |
| pstViDevAttr | vi设备相关属性 | 详见VI_DEV_ATTR_S | 输入        |

&emsp;&emsp;【返回值】

| **返回值** | **描述**     |
| ------- | ---------- |
| 0       | 成功         |
| 非0      | 失败，其值为错误码。 |

&emsp;&emsp;【错误码列表】

| **错误码**                  | **描述**   |
| ------------------------ | -------- |
| ERROR_VI_INVALID_DEVID   | 设备号不支持   |
| ERROR_VI_DEVID_NOT_OPEN  | 设备未打开    |
| ERROR_TYPE_INVALID_ARG   | 参数超出有效范围 |
| ERROR_VI_ATTR_PARM_WRONG | 参数错误     |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_vi.so

&emsp;&emsp;头文件：ak_vi.h

​        【接口调用】
