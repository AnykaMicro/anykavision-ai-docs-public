# 音频输入

&emsp;&emsp;音频采集模块（AI模块）主要负责采集音频数据，采集到的数据可以送往AENC进行编码。

&emsp;&emsp;AI模块对于不同平台，支持的设备不同。

| **芯片简称**    | **ADC** | **PDM** | **I2S0** | **I2S1** |
| ----------- | ------- | ------- | -------- | -------- |
| KM02G系列芯片 | 支持      | 支持      | 暂不支持     | 暂不支持     |

<br/>

## 多麦的dts配置

为了能够实现单双麦以及多麦的切换（如果硬件支持），需要修改对应的dts，修改后再重新编译生成dtb，再进行烧录。

1.进入目录os/kernel/arch/riscv/boot/dts/anyka，选择对应的dts,在dts中找到&adc_dac {...};

### 1.实现adc单麦

选择mic-info = <MIC_INFO_ADC_MIC0>。

 pinctrl-0 = <&speaker_en_pins>;

### 2. 实现adc双麦

 pinctrl-0 = <&speaker_en_pins>;

选择mic-info =  <(MIC_INFO_ADC_MIC0|MIC_INFO_ADC_MIC1)>

目前单麦只支持优先打开left mic0,不支持单麦单独使用right mic1

### 3.实现pdm双麦

选择pinctrl-0 = <&speaker_en_pins>,<&pdm_pins>;

选择 mic-info = <(MIC_INFO_PDM0|MIC_INFO_PDM1)>;

同时使能以下dev3的配置：
    dev3 {
        snd-dev = <SND_CARD_PDM_RECV>;
        snd-type = <AK_PCM_DEV_CAPTURE>;
    };

### 4.实现pdm4麦

选择pinctrl-0 = <&speaker_en_pins>,<&pdm_pins>;

选择 mic-info = <(MIC_INFO_PDM0|MIC_INFO_PDM1|MIC_INFO_PDM2|MIC_INFO_PDM3)>;

同时使能以下dev3的配置：
    dev3 {
        snd-dev = <SND_CARD_PDM_RECV>;
        snd-type = <AK_PCM_DEV_CAPTURE>;
    };

## 多设备多声道参数列表

支持多设备多通道主要解决以下几种情况：

| Input   condition       | DevId | SrcCnt | Chn  Cnt | sound mode     | get frame输出                                                           |
| ----------------------- | ----- | ------ | -------- | -------------- | --------------------------------------------------------------------- |
| 单声道ADC                  | ADC0  | 1      | 1        | MONO           | 输出 单声道数据                                                              |
| 2个麦克风采集，非麦克风阵列（相同控制器）   | ADC0  | 2      | 2        | MONO           | get frame(ch0);  get frame(ch1);分别取两路输出                               |
| 2个麦克风配置麦克风阵列只要原始数据，不做降噪 | ADC0  | 2      | 1        | MONO           | 2个麦克风数据交错模式存放在一个通道输出                                                  |
| 2个麦克风配置麦克风阵列多麦降噪        | ADC0  | 2      | 1        | MONO           | 输出单声道数据                                                               |
| 2个麦克风采集立体声              | ADC0  | 2      | 1        | STEREO （目前不支持） | 输出双声道立体声数据                                                            |
| 4个麦克风采集，非麦克风阵列（相同控制器）   | ADC0  | 4      | 4        | MONO           | get frame(ch0);  get frame(ch1);get frame(ch2);get frame(ch3);分别取4路输出 |
| 4个麦克风采集立体声              | ADC0  | 4      | 1        | 4声道立体声（目前不支持）  | 输出4声道环绕立体声                                                            |
| 2个麦克风采集，非麦克风阵列          | PDM0  | 2      | 2        | MONO           | get frame(ch0);  get frame(ch1);分别取2路输出                               |
| 2个麦克风配置麦克风阵列多麦降噪        | PDM0  | 2      | 1        | MONO           | 输出单声道数据                                                               |
| 2个麦克风采集立体声              | PDM0  | 2      | 1        | STEREO （目前不支持） | 输出双声道立体声数据                                                            |
| 4个麦克风采集，非麦克风阵列          | PDM0  | 4      | 4        | MONO           | get frame(ch0);  get frame(ch1);分别取4路输出                               |
| 4个麦克风配置麦克风阵列多麦降噪        | PDM0  | 4      | 1        | MONO           | 输出单声道                                                                 |

## AI降噪的配置
### audio_config.ini配置文件修改
1、audio_config.ini配置文件要打开以下配置，同时修改模型路径，例如：
```c
aidenoiseEna=1
modelName="/tmp/nfs/model_aidenoise"
numFrameDescriptor=2
```

2、由于AI降噪与传统降噪有冲突，所以打开AI降噪之后需要关闭NR与AGC的配置项。

### 内核dts要修改
内核dts修改以下配置
```c
#define RESERVED_NPU_RUN_SIZE         0x2000000 // 16MB
#define RESERVED_ION_BASE             0x43408000
#define RESERVED_CMA_BASE             0x4a408000
```

### 应用修改
应用需要添加AK_MPI_NPU_Init和AK_MPI_NPU_Deinit。
应用makefile需要添加akAIdenoise、ak_nne、plat_npu的链接。
应用需要调用AK_MPI_AUDIO_RegisterAIDenoise()进行AI降噪的注册。

### 加载驱动
应用运行之前需要运行以下命令加载驱动，其中path=/tmp/nfs/需要指向模型的存储路径。
```bash
insmod /lib/modules/5.10.111/kernel/drivers/base/firmware_loader/firmware_class.ko path=/tmp/nfs/
insmod /usr/modules/ak_npu.ko
```

&emsp;&emsp;【接口调用顺序】

```c
    /* Step 1: 配置设备公共属性 */
    AK_S32 s32AiDevId = DEV_ADC0;
    AUDIO_IN_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    pstParam.u32SrcCnt = 1;
    pstParam.u32ChnCnt = 1;
    // 配置ADC属性
    pstParam.stAdcConfig.enSourceType = AUDIO_ADC_SOURCE_MIC;
    pstParam.stAdcConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AI_SetPubAttr(s32AiDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_IN_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AI_GetPubAttr(s32AiDevId, &attr);
    if (ret) {
        return ERROR;
    }

    /* Step 2: 使能AI设备 */
    ret = AK_MPI_AI_Enable(s32AiDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: 导入通道参数 */
    ret = AK_MPI_AI_LoadConf(s32AiDevId, s32AiChnId, spchConfFile, spchConfSection);
    if (ret){
        return ERROR;
    }

    /* Step 4: 使能通道 */
    ret = AK_MPI_AI_EnableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    FRAME_S stFrame = {0};
    /* Step 5: 获取音频数据 */
    while (1) {
      ret = AK_MPI_AI_GetFrame(s32AiDevId, s32AiChnId, &stFrame, s32TimeOut, 0);
      if (ret) {
        return ERROR;
      }
      // Do something

      /* Step 6: 释放音频数据 */
      ret = AK_MPI_AI_ReleaseFrame(s32AiDevId, s32AiChnId, stFrame, 0);
      if (ret) {
        return ERROR;
      }
    }
    /* Step 7: 关闭通道 */
    ret = AK_MPI_AI_DisableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 8: 关闭设备 */
    ret = AK_MPI_AI_Disable(s32AiDevId);
    if (ret) {
        return ERROR;
    }
```

### AK_MPI_AI_EnableAecRefFrame

&emsp;&emsp;【描述】

&emsp;&emsp;配置需要该通道的Loopback数据。只能在AK_MPI_AI_EnableChn之前使用。配置了需要回音消除参考帧之后不能再配置所有音效参数（NR、AGC、AEC、EQ、ASLC等），数字音量放大也不能使用。此接口当前不可用。

配置了需要回音消除参考帧之后，调用AK_MPI_AI_GetFrame获取到的AI音频数据与Loopback数据是使用交错模式进行存放。

| 类别                             | 数据组织排列                                                                    |
| ------------------------------ | ------------------------------------------------------------------------- |
| 采集数据是单声道                       | \|Loopback\|Chn1\|Loopback\|Ch1\|......                                   |
| 采集数据是2个通道，配置了其中通道1需要Loopback数据 | \|Loopback1\|Chn1\|Ch2\|Loopback1\|Ch1\|Ch2\|......                       |
| 采集数据是2个通道，配置了两个通道都需要Loopback数据 | \|Loopback1\|Loopback2\|Chn1\|Ch2\|Loopback1\|Loopback2\|Ch1\|Ch2\|...... |
| 采集数据是4个通道，配置了4个通道都需要Loopback数据 | \|Loopback1\|Loopback2\|Loopback3\|Loopback4\|Chn1\|Ch2\|Ch3\|Ch4\|.....  |

&emsp;&emsp;【语法】

```c
    AK_S32 AK_MPI_AI_EnableAecRefFrame(AK_S32 s32AiDevId, AK_S32 s32AiChnId,
                                       AK_S32 s32AoDevId, AK_S32 s32AoChnId);
```

&emsp;&emsp;【参数】

| **参数名称**   | **描述**    | **取值范围**                                                  | **输入/输出** |
| ---------- | --------- | --------------------------------------------------------- | --------- |
| s32AiDevId | 音频输入模块设备号 | 参考AUDIO_AI_DEV_ID_E                                       | 输入        |
| s32AiChnId | 音频输入模块通道号 | 最小值为0，最大值参考AUDIO_IN_PARAM_S中u32ChnCnt取值，最大值=u32ChnCnt-1。  | 输入        |
| s32AoDevId | 音频输出模块设备号 | 参考AUDIO_AO_DEV_ID_E                                       | 输入        |
| s32AoChnId | 音频输出模块通道号 | 最小值为0，最大值参考AUDIO_OUT_PARAM_S中u32ChnCnt取值，最大值=u32ChnCnt-1。 | 输入        |

| ------------------------------ | ------------- |

| ERROR_TYPE_INVALID_ARG         | 参数不正确         |
| ERROR_AI_CAPTURE_START_ALREADY | 采集已经开始，不能进行设置 |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ai.so、libakaudiofilter.so、libplat_vqe.so或者libplat_ai.a、    libakaudiofilter.a、libplat_vqe.a、libplat_vqe.a

```c

    AK_S32 s32AiDevId = DEV_ADC0;
    AUDIO_IN_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    pstParam.u32SrcCnt = 1;
    pstParam.u32ChnCnt = 1;
    // 配置ADC属性
    pstParam.stAdcConfig.enSourceType = AUDIO_ADC_SOURCE_MIC;
    pstParam.stAdcConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AI_SetPubAttr(s32AiDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_IN_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AI_GetPubAttr(s32AiDevId, &attr);
    if (ret) {
        return ERROR;
    }

    /* Step 2: 使能AI设备 */
    ret = AK_MPI_AI_Enable(s32AiDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: 设置需要回音消除参考帧 */
    AK_S32 s32AiChnId = 0;
    AK_S32 s32AoDevId = DEV_DAC0;
    AK_S32 s32AoChnId = 0;
    ret = AK_MPI_AI_EnableAecRefFrame(s32AiDevId, s32AiChnId, s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }

    /* Step 4: 使能通道 */
    ret = AK_MPI_AI_EnableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    FRAME_S stFrame = {0};
    /* Step 5: 获取音频数据 */
    while(1) {
      ret = AK_MPI_AI_GetFrame(s32AiDevId, s32AiChnId, &stFrame, s32TimeOut, 0);
      if (ret) {
        return ERROR;
      }
      // Do something

      /* Step 6: 释放音频数据 */
      ret = AK_MPI_AI_ReleaseFrame(s32AiDevId, s32AiChnId, stFrame, 0);
      if (ret) {
        return ERROR;
      }
    }
    /* Step 7: 关闭通道 */
    ret = AK_MPI_AI_DisableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 8: 关闭设备 */
    ret = AK_MPI_AI_Disable(s32AiDevId);
    if (ret) {
        return ERROR;
    }
```

## 音量设置/获取

### **AK_MPI_AI_SetGain**

&emsp;&emsp;【描述】

&emsp;&emsp;模拟音量调整。根据不同的使用场景，麦克风的模拟增益配置说明如下：

| ---------------------- | ----------- |
| ERROR_AI_DEV_ID_NULL   | AI设备句柄为空    |
| ERROR_AI_VQE_ERROR     | 调用声音质量增强库错误 |
| ERROR_TYPE_INVALID_ARG | 参数不正确       |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ai.so、libakaudiofilter.so、libplat_vqe.so或者libplat_ai.a、    libakaudiofilter.a、libplat_vqe.a

&emsp;&emsp;头文件：ak_ai.h

&emsp;&emsp;【接口调用顺序】

```c
    /* Step 1: 配置设备公共属性 */
    AK_S32 s32AiDevId = DEV_ADC0;
    AUDIO_IN_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    pstParam.u32SrcCnt = 1;
    pstParam.u32ChnCnt = 1;
    // 配置ADC属性
    pstParam.stAdcConfig.enSourceType = AUDIO_ADC_SOURCE_MIC;
    pstParam.stAdcConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AI_SetPubAttr(s32AiDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_IN_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AI_GetPubAttr(s32AiDevId, &attr);
    if (ret) {
        return ERROR;
    }

    /* Step 2: 使能AI设备 */
    ret = AK_MPI_AI_Enable(s32AiDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: 导入通道参数 */
    ret = AK_MPI_AI_LoadConf(s32AiDevId, s32AiChnId, spchConfFile, spchConfSection);
    if (ret){
        return ERROR;
    }

    /* Step 4: 使能通道 */
    ret = AK_MPI_AI_EnableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    FRAME_S stFrame = {0};
    /* Step 5: 获取音频数据 */
    while(1) {
      ret = AK_MPI_AI_GetFrame(s32AiDevId, s32AiChnId, &stFrame, s32TimeOut, 0);
      if (ret) {
        return ERROR;
      }
      // Do something
      ret = AK_MPI_AI_SetDigitalGain(s32AiDevId, s32AiChnId, s32DGain);
      if (ret) {
        return ERROR;
      }
      ret = AK_MPI_AI_GetDigitalGain(s32AiDevId, s32AiChnId, ps32DGain);
      if (ret) {
        return ERROR;
      }

      /* Step 6: 释放音频数据 */
      ret = AK_MPI_AI_ReleaseFrame(s32AiDevId, s32AiChnId, stFrame, 0);
      if (ret) {
        return ERROR;
      }
    }
    /* Step 7: 关闭通道 */
    ret = AK_MPI_AI_DisableChn(s32AiDevId, s32AiChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 8: 关闭设备 */
    ret = AK_MPI_AI_Disable(s32AiDevId);
    if (ret) {
        return ERROR;
    }
```

&emsp;&emsp;【接口重入性】

&emsp;&emsp;函数可重入。

> **注意：**
>
> 1）函数可重入，支持在运行过程中调整采集音量。该接口调整的是数字音量，数字音量通过libakaudiofilter进行数字放大，设置后即生效。
>
> 2）如数字放大音量为0，则表示不进行数字放大。
>
> 3）接口的第二个参数dB就是放大的倍数，如dB=2，即把音量放大2dB，dB可以是负数，如果dB=-2，代表把音量缩小2dB。
>
> 4）设置此接口的dB值与配置AK_MPI_AI_SetVqeAttr接口的dB值是一样的效果，如果使用了AK_MPI_AI_SetVqeAttr配置了默认的数字音量，需要调整数字音量的时候，请在AK_MPI_AI_SetVqeAttr配置的后面使用AK_MPI_AI_SetDigitalGain调整音量。

```c
    {
        AK_CHAR ReplaceName[DUMP_FILE_PATH_LEN];

    }

    if (ret) {
        return ERROR;
    }

    /* Step 3: 设置dump文件 */
    ret = AK_MPI_AI_SetDumpCb(s32AiDevId, s32AiChnId, DumpFileDataToLocalPath);

      }

        return ERROR;
    }
    /* Step 8: 关闭设备 */
```

## 性能调整接口

### AK_MPI_AI_SetDrvBufPeriods

&emsp;&emsp;【描述】

&emsp;&emsp;此接口调整音频采集驱动和音频回音消除驱动存储音频数据的buffer数量。目前音频采集驱动和音频回音消除驱动的存储结构为buffer * （buffer块数）。Periods为音频采集驱动的buffer块的数量，通过设置buffer的块数来设置音频采集驱动的buffer的总大小，periods默认值为8。一般在系统负荷较重、音频数据没有办法及时获取的情况下使用。

【语法】

```c
    AK_S32 AK_MPI_AI_SetDrvBufPeriods(AK_S32 s32AiDevId,
```

&emsp;&emsp;【参数】

| **参数名称**     | **描述**            | **取值范围**                | **输入/输出** |

### AK_MPI_AI_SetThreadPriority

&emsp;&emsp;【描述】

&emsp;&emsp;此接口可以调整AI内部线程mpp_ai和回音消除线程mpp_loopback的优先级。mpp_ai为音频采集AI模块的内置线程，默认线程优先级为50。mpp_loopback为音频回音消除线程，默认线程优先级为50。在应用实际运行中可能因为系统的负荷较重或总线程数较多，使mpp_ai或mpp_loopback的线程调度实时性降低，导致数据丢失或覆盖。此时可通过提高mpp_ai或mpp_loopback的线程优先级来提高其实时性。这样避免出现数据丢失或覆盖，减少或解决采集的音频不连续的问题。


## sample相关说明

### sample命令和参数

运行此sample前，需要先insmod ak_pcm.ko，一般开启都会默认加载。

| 输入参数（短参） | 输入参数（长参）       | **输入参数说明**                                                                   |
| -------- | -------------- | ---------------------------------------------------------------------------- |
| h        | help           | 打印帮助信息。                                                                      |
| s        | sample-rate    | 音频采样率，支持8000和16000采样率。                                                       |
| p        | path           | PCM文件保存路径，无需指定文件名，在文件路径末尾要带"/"符号，<br/>例如路径可以配置为: /mnt/。                      |
| t        | second         | 采集时间，以秒为单位。                                                                  |
| d        | device-type    | 设备类型,0:DEV_ADC,1:DEV_PDM,2:DEV_I2S0_AI。                                      |
| f        | config-file    | 音频配置文件全路径。                                                                   |
| e        | config-section | 音频配置文件section name， def_near：用于ai单麦克风；two_array_near：用于AI双麦克风; def_far：用于AO。 |

<br/>

### sample存储和文件命令

（1）sample输出的文件格式默认使用PCM格式。
（2）sample输出的文件默认存储到/mnt/目录下。
（3）sample输出的文件名默认使用yyyymmdd-ddmmss采样率通道数时长（ms）设备.pcm 。

### 应用案例

（1）ak_ai_sample -s 16000 -p /mnt/ -t 20 -d 0 -f /etc/config/audio_config.ini -e def_near
