## 第一章 概述

本文档介绍AI眼镜SDK的方案参考设计，目的是供您在开发过程中快速编译、烧写并运行眼镜程序。

### 1.3 缩写说明

本文会用到如下缩写词：

- **APP**：眼镜手机端 Anyka_Glasses 程序
- **BT**：蓝牙模块（AK1090系列芯片）
- **RTT**：运行在 KM02G系列芯片 上的 RT-Thread 系统
- **LINUX**：运行在 KM02G系列芯片 上的 Linux 系统

## 第三章 固件编译

### 3.1 获取SDK并准备编译

1. 按[SDK下载](sdk-download.md)克隆公开的 `AnykaMicro/sdk-km02g`，进入 SDK 根目录。
2. 按[编译环境配置](build-environment.md)安装主机软件，用 SDK 脚本校验、重打包并安装思澈下载站的 V1.00 工具链，再将交叉编译器加入 `PATH`。
3. 首次打包时，SDK 会下载 BusyBox 和 mtd-utils 源码并生成 ramdisk。离线打包可提前将这两个源码包放入 `tools/`。
4. 把 `rootfs/config/shadow` 复制到 `rootfs/config.local/`，在副本的 `root` 行中设置密码哈希（`openssl passwd -6`），不要修改受 git 跟踪的 `rootfs/config/shadow`。每台设备或每个构建使用唯一的强密码，不要在设备上发布共用的开发密码，也不要提交或共享密码哈希。

### 3.2 编译程序

编译程序：可执行 `make` 命令，编译所有模块，生成升级包 `update.bin`，以及 `ramfs.img` 和 `usr.jffs2`（均位于 `tools/ota` 文件夹下）。或执行 `make clean; make app; make install` 分步骤编译（`make install` 需要先编译好应用）。

分步编译：

```bash
make clean        # 清除
make app          # 编译 app
make install      # 打包镜像，需要先执行 make app
```

## 第五章 功能说明

```{note}
以下涉及手机 APP 的操作（录像时长设置、AI识图、图库导入、实时视频预览）需要 Anyka_Glasses APP。该 APP 尚未随本次版本发布，开发者可在后续版本中补充安装包。
```

### 5.1 拍照

**操作方式：** 短按一下功能键\
**提示音：** 拍照开始播放"滴"，拍照完成播放"咔嚓"\
**后续操作：** 拍照结束后关机KM02G系列芯片

### 5.2 录像

**操作方式：** 长按功能键3秒开始录像，短按一下功能键结束录像\
**提示音：** 录像开始播放"叮"，录像完成播放"叮叮"\
**默认录像时长：** 1分钟（如需不同时长，快速按5次APP版本号，在录像定时时长处输入1-600，单位秒。设备端接受任意正数时长，小于或等于0时按600秒录像）\
**后续操作：** 录像结束后关机KM02G系列芯片

### 5.3 AI识图

**前提条件：** 手机绑定好眼镜\
**操作方式：** 打开手机APP，进入AI识图界面，短按两下功能键，图片显示在APP识图界面，识别结果文字可显示在识图界面，并且可通过眼镜喇叭播放识别结果\
**后续操作：** 识图结束后关机KM02G系列芯片

### 5.4 开关机

操作方式：长按开关键3秒表示关机，短按1下开关机键表示开机。
提示音：关机播报“关机”，开机播报“开机”。

### 5.5 查看眼镜拍摄的录像与图片

操作方式1：眼镜通过USB线连接电脑，眼镜会以U盘方式呈现在电脑端。录像路径：U盘根目录/Videos/; 拍照路径：U盘根目录/Pictures/。

**操作方式2：** 打开手机APP，绑定眼镜设备后，进入图库管理界面，可将录像和照片导入到手机上。

### 5.6 实时视频预览

打开手机APP，绑定眼镜设备之后，进入视频直播界面，可查看设备实时视频。
