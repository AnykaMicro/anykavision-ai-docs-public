# Getting Started

Welcome to AnykaVision AI. AnykaVision AI gives chip and system developers a one-stop set of technical resources and a place to exchange ideas, so you can design products and develop applications efficiently. It covers hardware, software and system applications with a complete technical support system. It also brings together a wide range of technical documents, including development guides, API references and FAQs, to shorten the learning curve and make development more efficient.

## Start here

Follow these steps to go from getting the SDK to running your firmware on the reference board:

1. **Get the SDK**: [SDK Download](../software/board/sdk-download.md)
2. **Build**: [Build Environment Setup](../software/board/build-environment.md)
3. **Flash**: [Firmware Flashing](../software/board/firmware-flashing.md)
4. **Develop applications**: [Application Development](../software/board/app-development.md)

The Anyka_Glasses companion phone app has not been published with this release. The pages under [App Development](../software/app/index.md) are for reference only; the developer can add the app package in a later release.

For an overview of the whole flow and of the board's basic operation, read the [Quick Development Guide](../software/board/quick-development.md).

## Who this is for

AnykaVision AI is for:

- **Software developers**: drivers, sample code, development tools and development guides to help you build and validate application designs quickly.
- **Hardware developers**: chip specifications, reference designs and reference board materials to help you understand and use the chips' capabilities quickly.

## Tips

**1. Search by keyword**

- If you are not sure where something is, use the search box.
- Enter a keyword, such as a feature name, API name or hardware module name, to find related content quickly.

**2. Learn from the sample code**

- AnykaVision AI includes a lot of sample code. Try it on a real project to deepen your understanding of the documentation.

**3. Updates**

- [SDK Download](../software/board/sdk-download.md) lists the KM02G source repository and cross-toolchain download.
