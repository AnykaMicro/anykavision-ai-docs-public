# Audio Tool Service

## Overview

&emsp;&emsp;The ATS module starts a server on the device and waits for the PC audio-debugging-tool client to connect. After the connection succeeds, it exchanges data with the tool.

<br/>

## API Reference

&emsp;&emsp;The following table lists the APIs provided by this module.

<br/>

## Function List

| **Function**          | **Description**    |
| --------------------- | ------------------ |
| AK_EXT_ATS_GetVersion | Gets the version number |
| AK_EXT_ATS_Start      | Starts the ATS service |
| AK_EXT_ATS_Stop       | Stops the ATS service |

<br/>

## Get the Version Number

&emsp;&emsp;AK_EXT_ATS_GetVersion

&emsp;&emsp;【Description】

&emsp;&emsp;Gets the version number.

&emsp;&emsp;【Syntax】

```c
const AK_CHAR* AK_EXT_ATS_GetVersion(AK_VOID);
```

&emsp;&emsp;【Return Values】

| **Return value** | **Description** |
| ---------------- | --------------- |
| Module version number | Success |
| NULL | Failure |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Libraries: libplat_ai.a, libplat_ao.a, libplat_ats.a, libplat_vqe.a, and libakaudiofilter.a; or libplat_ai.so, libplat_ao.so, libplat_ats.so, libplat_vqe.so, and libakaudiofilter.so

&emsp;&emsp;Header: ak_ats.h

&emsp;&emsp;【Call Order】

&emsp;&emsp;May be called at any point.

&emsp;&emsp;【Reentrancy】

&emsp;&emsp;This function is reentrant.

## Start the ATS Service

AK_EXT_ATS_Start

&emsp;&emsp;【Description】

&emsp;&emsp;Starts the ATS service.

&emsp;&emsp;【Syntax】

```c
    AK_S32 AK_EXT_ATS_Start(AK_U32 u32Port);
```

&emsp;&emsp;【Return Values】

| **Return value** | **Description** |
| ---------------- | --------------- |
| AK_SUCCESS | Success |
| Other | See the error codes. |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Libraries: libplat_ai.a, libplat_ao.a, libplat_ats.a, libplat_vqe.a, and libakaudiofilter.a; or libplat_ai.so, libplat_ao.so, libplat_ats.so, libplat_vqe.so, and libakaudiofilter.so

&emsp;&emsp;Header: ak_ats.h

&emsp;&emsp;【Call Order】

&emsp;&emsp;Call after `AK_BASE_SdkInit` and before `AK_BASE_SdkExit`.

&emsp;&emsp;【Reentrancy】

&emsp;&emsp;This function is reentrant.

## Stop the ATS Service

AK_EXT_ATS_Stop

&emsp;&emsp;【Description】

&emsp;&emsp;Stops the ATS service.

&emsp;&emsp;【Syntax】

```c
AK_S32 AK_EXT_ATS_Stop(AK_VOID);
```

&emsp;&emsp;【Return Values】

| **Return value** | **Description** |
| ---------------- | --------------- |
| AK_SUCCESS | Success |
| Other | See the error codes. |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Libraries: libplat_ai.a, libplat_ao.a, libplat_ats.a, libplat_vqe.a, and libakaudiofilter.a; or libplat_ai.so, libplat_ao.so, libplat_ats.so, libplat_vqe.so, and libakaudiofilter.so

&emsp;&emsp;Header: ak_ats.h

&emsp;&emsp;【Call Order】

&emsp;&emsp;Call after `AK_EXT_ATS_Start` and before `AK_BASE_SdkExit`.

&emsp;&emsp;【Reentrancy】

&emsp;&emsp;This function is reentrant.
