# ISP Tuning Tool Service

## Overview

&emsp;&emsp;The ITS module is a device-side service used with the ISP tuning tool. It receives, sends, and processes tool operations over a network connection.

<br/>

## API Reference

&emsp;&emsp;This module provides the APIs listed below.

| **Function** | **Description** |
| --------------------- | ---------------- |
| AK_EXT_ITS_GetVersion | Gets the module version. |
| AK_EXT_ITS_Start | Starts the ITS service. |
| AK_EXT_ITS_Stop | Stops the ITS service. |
<br/>

## Getting Version Information

### **AK_EXT_ITS_GetVersion**

&emsp;&emsp;【Description】

&emsp;&emsp;Gets the module version.

&emsp;&emsp;【Syntax】

```c
    const AK_CHAR* AK_EXT_ITS_GetVersion(AK_VOID);
```

&emsp;&emsp;【Return Value】

| **Return value** | **Description** |
| ---------- | -------- |
| Module version | Success |
| NULL | Failure |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Library: libapp_its.a or libapp_its.so

&emsp;&emsp;Header: ak_its.h

&emsp;&emsp;【Call Sequence】

&emsp;&emsp;This function may be called at any point.

<br/>

## Starting and Stopping the Service

### **AK_EXT_ITS_Start**

&emsp;&emsp;【Description】

&emsp;&emsp;Starts the ITS service.

&emsp;&emsp;【Syntax】

```c
    AK_VOID AK_EXT_ITS_Start(AK_U32 u32Port);
```

&emsp;&emsp;【Parameters】

| **Parameter** | **Description** | **Value range** | **Input/Output** |
| ------------ | -------- | ------------------------------------------------------------ | ------------- |
| u32Port | Port | May be customized. When the tool connects to the device, its port must match the port configured by this interface. The tool's default port is 8765 and can be changed when connecting. | Input |

> **Security note:** The ITS service is for debugging only. Start it only on an isolated development network, and restrict connecting devices with host and network firewalls. Call `AK_EXT_ITS_Stop` when debugging is complete. Changing the port number is not a substitute for access control.

&emsp;&emsp;【Return Value】

| **Return value** | **Description** |
| ---------- | -------- |
| AK_VOID    | -        |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Library: libapp_its.a or libapp_its.so

&emsp;&emsp;Header: ak_its.h

&emsp;&emsp;【Call Sequence】

```c
    AK_EXT_ITS_Start(8765);
    ...
    AK_EXT_ITS_Stop();
```

&emsp;&emsp;【Paired Interface】

&emsp;&emsp;AK_EXT_ITS_Stop;

<br/>

&emsp;&emsp;【Description】

&emsp;&emsp;【Parameters】

| **Parameter** | **Description** | **Value range** | **Input/Output** |
| ------------ | -------- | ------------ | ------------- |
| AK_VOID      | -        | -            | -             |

&emsp;&emsp;【Return Value】

| **Return value** | **Description** |
| ---------- | -------- |
| AK_VOID    | -        |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Library: libapp_its.a or libapp_its.so

&emsp;&emsp;Header: ak_its.h

&emsp;&emsp;【Call Sequence】

```c
    AK_EXT_ITS_Start(8765);
    ...
    AK_EXT_ITS_Stop();
```

&emsp;&emsp;【Paired Interface】

&emsp;&emsp;AK_EXT_ITS_Start;
