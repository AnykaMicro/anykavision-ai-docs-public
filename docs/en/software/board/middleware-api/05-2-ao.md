# Audio Output

## Overview

&emsp;&emsp;The audio-output (AO) module receives the bitstream decoded by ADEC and sends it to an external playback device using the configured output protocol.

&emsp;&emsp;The AO module supports different devices on different platforms.

| **Chip family** | **DAC** | **I2S0** |
| ------------ | ------- | -------- |
| KM02G series | Supported | Not currently supported |

<br/>

## Enabling and Disabling the Module

### **AK_MPI_AO_SetPubAttr**

&emsp;&emsp;【Description】

&emsp;&emsp;Sets the AO device attributes.

&emsp;&emsp;【Syntax】

```c
    AK_S32 AK_MPI_AO_SetPubAttr(AK_S32 s32AoDevId, AUDIO_OUT_PARAM_S *pstParam);
```

&emsp;&emsp;【Parameters】

| **Parameter** | **Description** | **Value range** | **Input/Output** |
| ------------ | ------------------------ | --------------------- | ------------- |
| s32AoDevId | audio-output module device ID | See AUDIO_AO_DEV_ID_E | Input |
| pstParam | audio-output module input-parameter pointer | See AUDIO_OUT_PARAM_S | Input |

&emsp;&emsp;【Return Values】

| **Return value** | **Description** |
| ---------- | -------------- |
| 0 | Success. |
| Other | See the error codes. |

&emsp;&emsp;【Error Codes】

| **Error code** | **Description** |
| ------------------------- | ------------------ |
| ERROR_AO_DEV_ALREADY_OPEN | The AO device is already open |
| ERROR_TYPE_POINTER_NULL | parameter pointer is null |
| ERROR_TYPE_INVALID_ARG | invalid parameter |
| ERROR_AO_DEV_ID_NULL | AO internal device handle is null |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Libraries: libplat_ao.so. libakaudiofilter.so. libplat_vqe.so or libplat_ao.a. libakaudiofilter.a. libplat_vqe.a

&emsp;&emsp;Header: ak_ao.h

&emsp;&emsp;【Call Sequence】

```c
    /* Step 1: Configure common device attributes */
    AK_S32 s32AoDevId = DEV_DAC0;
    AUDIO_OUT_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    stAoParam.u32ChnCnt = 1;
    stAoParam.u32SrcCnt = 1;
    // configure DACattribute
    pstParam.stDacConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AO_SetPubAttr(s32AoDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_OUT_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AO_GetPubAttr(s32AoDevId, &attr);
    if (ret) {
        return ERROR;
    }

     /* Step 2: Enable the AO device */
    ret = AK_MPI_AO_Enable(s32AoDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: Set channel attributes */
    ret = AK_MPI_AO_LoadConf(s32AoDevId, s32AoChnId, spchConfFile, spchConfSection);
    if (ret) {
        return ERROR;
    }

    /* Step 4: Enable the channel */
    ret = AK_MPI_AO_EnableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }

    FRAME_S stFrame = {0};
    /* Step 5: Play audio data */
    while(1) {
      // Do something*
      ret = AK_MPI_AO_SendFrame(s32AoDevId, s32AoChnId, pu8SendPcmData,s32SendPcmLen, 	               ps32PlayPcmLen, s32TimeOut);
      if (ret) {
         return ERROR;
      }

      if (PlayEnd) {
         ret = AK_MPI_AO_GetBufStatus(s32AoDevId, s32AoChnId, &stBufStatus);
	     if (ret) {
                return ERROR;
         }
         AoRemainLen = stBufStatus.s32VqeBufRemainLen + stBufStatus.s32DevBufRemainLen;
         /*get flush time to play remain data*/
         FlushTime =  AudioLenToInterval(s32SampleRate, AK_AUDIO_SMPLE_BIT_16,
                                         s32SoundMode, AoRemainLen);
         ret = AK_MPI_AO_Flush(s32AoDevId, s32AoChnId);
	     if (ret) {
                return ERROR;
         }
      }
    }
    /* Step 6: Disable the channel */
    ret = AK_MPI_AO_DisableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 7: Disable the device */
    ret = AK_MPI_AO_Disable(s32AoDevId);
    if (ret) {
        return ERROR;
    }
```

&emsp;&emsp;【Paired Interface】

```c
AK_S32 AK_MPI_AO_GetPubAttr(AK_S32 s32AoDevId, AUDIO_OUT_PARAM_S *pstParam);
```

&emsp;&emsp;【Reentrancy】

&emsp;&emsp;After calling `AK_MPI_AO_Open`, call `AK_MPI_AO_Close` before opening it again; otherwise an error is reported.

> **Note:** The AO module can open a particular device only once; opening the same device again returns an error.

| ERROR_TYPE_INVALID_ARG | invalid parameter |
| ERROR_AO_DRIVER_FAILED | driver setting failed |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Libraries: libplat_ao.so. libakaudiofilter.so. libplat_vqe.so or libplat_ao.a. libakaudiofilter.a. libplat_vqe.a

&emsp;&emsp;Header: ak_ao.h

&emsp;&emsp;【Call Sequence】

```C
 /* Step 1: Configure common device attributes */
    AK_S32 s32AoDevId = DEV_DAC0;
    AUDIO_OUT_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    stAoParam.u32ChnCnt = 1;
    stAoParam.u32SrcCnt = 1;
    // configure DACattribute
    pstParam.stDacConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AO_SetPubAttr(s32AoDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_OUT_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AO_GetPubAttr(s32AoDevId, &attr);
    if (ret) {
        return ERROR;
    }

     /* Step 2: Enable the AO device */
    ret = AK_MPI_AO_Enable(s32AoDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: Set channel attributes */
    ret = AK_MPI_AO_LoadConf(s32AoDevId, s32AoChnId, spchConfFile, spchConfSection);
    if (ret) {
        return ERROR;
    }

    /* Step 4: Enable the channel */
    ret = AK_MPI_AO_EnableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }

    FRAME_S stFrame = {0};
    /* Step 5: Play audio data */
    while(1) {
      // Do something*
      ret = AK_MPI_AO_SetGain(s32AoDevId,  s32AoChnId, s32Gain);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_GetGain(s32AoDevId,  s32AoChnId, ps32Gain);
      if (ret) {
         return ERROR;
      }

      ret = AK_MPI_AO_SetMute(s32AoDevId, s32AoChnId, s32Enable, NULL);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_GetMute(s32AoDevId, s32AoChnId, ps32Enable, NULL);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_SendFrame(s32AoDevId, s32AoChnId, pu8SendPcmData,s32SendPcmLen, 	               ps32PlayPcmLen, s32TimeOut);
      if (ret) {
         return ERROR;
      }

    }
    /* Step 6: Disable the channel */
    ret = AK_MPI_AO_DisableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 7: Disable the device */
    ret = AK_MPI_AO_Disable(s32AoDevId);
    if (ret) {
        return ERROR;
    }
```

### AK_MPI_AO_SetThreadPriority


| EQ | | |
| eqLoad | Whether to load the EQ module | 0: do not load; 1: load. |
| eqmode | EQ mode | Currently must be `user`. |

| bands | Number of equalizers; up to 10 | [0,10]. When greater than 0, use `bands="<#band>, <band0_param>, <band1_param>, ..."`, where each `bandx_param` is `<type> <freq_Hz> <gain_dB> <Q> <bypass>`. `type`: hpf/HPF, lpf/LPF, hsf/HSF, lsf/LSF, or pf1/PF1. `freq_Hz`: 20 <= freq <= sample rate/2/1.2, in Hz. `gain_dB`: (-32,32), default 0; a gain of 0 is invalid for lsf, hsf, or pf1. `Q`: 0 <= x.xxx < sample rate/(2*freqs), with x.xxx < 64.000; default 0. `bypass`: 0 = apply this setting; 1 = ignore it. |
