# Video Input

## Overview

&emsp;&emsp;The video-input module (VI) captures video data and sends it to VPSS for processing.

| **Chip** | **ISP support** |
| ----------- | ----------- |
| KM02G series | Supported |

<br/>

## API Reference

&emsp;&emsp;This module provides the APIs listed below:

| **Data structure**        | **Description**   |
| --------------- | -------- |
| VI_INTF_MODE_E | VI input-interface type |
| VI_CHN_MODE_E | VI channel operating mode |
| VI_DEV_ATTR_S | VI device attributes |
| VI_CHN_ATTR_S | VI channel attributes |
| VI_RECTANGLE_S | Video resolution |
| VI_FRAME_INFO_S | Frame structure |

<br/>

| **Function**               | **Description**         |
| ---------------------- | -------------- |
| AK_MPI_VI_GetVersion | Gets the video-input library version. |
| AK_MPI_VI_CreateDev | Creates a VI device. |
| AK_MPI_VI_DestroyDev | Destroys a VI device. |
| AK_MPI_VI_SetDevAttr | Sets VI device attributes. |
| AK_MPI_VI_GetDevAttr | Gets VI device attributes. |
| AK_MPI_VI_SetChnAttr | Sets VI channel attributes. |
| AK_MPI_VI_GetChnAttr | Gets VI channel attributes. |
| AK_MPI_VI_EnableDev | Enables a VI device. |
| AK_MPI_VI_DisableDev | Disables a VI device. |
| AK_MPI_VI_EnableChn | Enables a VI channel. |
| AK_MPI_VI_DisableChn | Disables a VI channel. |
| AK_MPI_VI_BindVpssGrp | Binds a VPSS GROUP. |
| AK_MPI_VI_SetSensorFps | Sets the sensor frame rate. |
| AK_MPI_VI_GetSensorFps | Gets the sensor frame rate. |
| AK_MPI_VI_GetSensorId | Gets the device sensor ID. |
| AK_MPI_VI_GetSensorRes | Gets the sensor resolution. |
| <br/>                  |                |

## Data Structures

### VI_INTF_MODE_E

&emsp;&emsp;【Notes】

&emsp;&emsp;VI input-interface types.

&emsp;&emsp;【Definition】

```c
typedef enum akVI_INTF_MODE_E {
    VI_INTF_DVP = 0,                 //DVP Parallel interface
    VI_INTF_MIPI_1,                     //MIPI Serial Single-Line Interface.
    VI_INTF_MIPI_2,                     //MIPI Serial Two-Line Interface.
    VI_INTF_MULTI_DVP,               //Multiple camera DVP interface.
    VI_INTF_MULTI_MIPI_1,            //Multiple camera MIPI Single-Line Interface.
    VI_INTF_MULTI_MIPI_2,            //Multiple camera MIPI Two-Line Interface.
    VI_INTF_TOTAL
}VI_INTF_MODE_E;
```

&emsp;&emsp;【Members】

| **Member**             | **Description**               |
| -------------------- | -------------------- |
| VI_INTF_DVP | DVP parallel interface |
| VI_INTF_MIPI_1 | MIPI serial 1-lane interface |
| VI_INTF_MIPI_2 | MIPI serial 2-lane interface |
| VI_INTF_MULTI_DVP | Multi-camera DVP interface (not currently supported; reserved design) |
| VI_INTF_MULTI_MIPI_1 | Multi-camera MIPI 1-lane interface |
| VI_INTF_MULTI_MIPI_2 | Multi-camera MIPI 2-lane interface |
| VI_INTF_TOTAL | Total number of types |

&emsp;&emsp;【Related Functions】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

### VI_CHN_MODE_E

&emsp;&emsp;【Notes】

&emsp;&emsp;VI channel operating modes.

&emsp;&emsp;【Definition】

```c
typedef enum akVI_CHN_MODE_E
{
    VI_CHN_MODE_USER,
    VI_CHN_MODE_AUTO,
    VI_CHN_MODE_TOTAL
}VI_CHN_MODE_E;
```

&emsp;&emsp;【Members】

| **Member**          | **Description** |
| ----------------- | ------ |
| VI_CHN_MODE_USER | User mode |
| VI_CHN_MODE_AUTO | Auto mode |
| VI_CHN_MODE_TOTAL | Total number of modes |

&emsp;&emsp;【Related Functions】

```c
AK_S32 AK_MPI_VI_SetChnAttr(AK_S32 s32DevId, AK_S32 s32ChnId, const VI_CHN_ATTR_S *pstViChnAttr);
```

> Note: User mode allocates memory so the user layer can obtain frames; AK_MPI_VI_GetFrame produces data only in this mode. Auto mode does not provide extra memory for user-layer frame retrieval. Both modes can bind to VPSS, but User mode additionally allocates memory to store video-frame image data for the application layer.

### VI_DEV_ATTR_S

&emsp;&emsp;【Notes】

&emsp;&emsp;VI device attributes. Cropping is supported.

&emsp;&emsp;【Definition】

```c
typedef struct akVI_DEV_ATTR_S
{
    AK_U32                u32Width;           //vi dev width
    AK_U32                u32Height;          //vi dev height
    CROP_INFO_S            stCropInfo;         //vi crop info
    VI_INTF_MODE_E        enIntfMode;         //vi interface mode
    PIXEL_FORMAT_E         enInputPixFmt;      //vi dev input pixel formate
    AK_U32                 u32Fps;             //sensor input fps
    AK_BOOL                bMirror;            //if mirror
    AK_BOOL                bFlip;              //if flip
}VI_DEV_ATTR_S;
```

&emsp;&emsp;【Members】

| **Member**      | **Description**           |
| ------------- | ---------------- |
| u32Width | VI device input width. |
| u32Height | VI device input height. |
| stCropInfo | Resolution information. |
| enIntfMode | VI device-interface type. |
| enInputPixFmt | Pixel format of sensor input data. |
| u32Fps | Sensor input frame rate. |
| bMirror | Whether to mirror horizontally. |
| bFlip | Whether to flip vertically. |

&emsp;&emsp;【Related Functions】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

### VI_CHN_ATTR_S

&emsp;&emsp;【Notes】

&emsp;&emsp;VI channel attributes. Downscaling is supported; upscaling is not. The output-to-device resolution ratio determines the downscaling ratio.

&emsp;&emsp;【Definition】

```c
typedef struct akVI_CHN_ATTR_S
{
    AK_U32                u32Width;           //vi chn width
    AK_U32                u32Height;          //vi chn height
    AK_U32                u32MaxPerFrameSize; //vi chn buffer size
    PIXEL_FORMAT_E         enOutputPixFmt;     //vi chn ouput pixel formate
    AK_U32                 u32Fps;             //vi chn output fps
    AK_U32                u32FrameDepth;      //vi chn frame depth
    VI_CHN_MODE_E        enMode;             //vi chn mode
}VI_CHN_ATTR_S;
```

&emsp;&emsp;【Members】

| **Member**           | **Description**                         |
| ------------------ | ------------------------------ |
| u32Width | VI CHN output and crop width. |
| u32Height | VI CHN output and crop height. |
| u32MaxPerFrameSize | Maximum per-frame buffer size in KB; 0 uses the default size. |
| enOutputPixFmt | VI CHN output pixel format. |
| u32Fps | VI CHN output frame rate. |
| u32FrameDepth | Number of internally buffered frames; used with u32MaxPerFrameSize. |
| enMode | Channel operating mode. |

&emsp;&emsp;【Related Functions】

```c
    AK_S32 AK_MPI_VI_SetChnAttr(AK_S32 s32DevId, AK_S32 s32ChnId,
                                    const VI_CHN_ATTR_S *pstViChnAttr);
```

## Interfaces

### **AK_MPI_VI_CreateDev**

&emsp;&emsp;【Description】

&emsp;&emsp;Creates a VI device. Creating multiple devices time-multiplexes the VI hardware.

&emsp;&emsp;【Syntax】

```c
    AK_S32 AK_MPI_VI_CreateDev(AK_S32 s32DevId,const VI_DEV_ATTR_S *pstViDevAttr);
```

&emsp;&emsp;【Parameters】

| **Parameter** | **Description** | Value range | **Input/Output** |
| ------------ | --------- | ----- | --------- |
| s32DevId     | Device ID      | [0-3] | Input        |
| pstViDevAttr | VI device-attribute structure | - | Input |

&emsp;&emsp;【Return Value】

| **Return value** | **Description**    |
| ------- | --------- |
| 0       | Success        |
| Nonzero      | Failure; the value is an error code. |

&emsp;&emsp;【Error Code List】

| **Error code**                | **Description** |
| ---------------------- | ------ |
| ERROR_VI_INVALID_DEVID | Unsupported device number |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Library: libplat_vi.so

&emsp;&emsp;Header: ak_vi.h

> Note: Call AK_MPI_VI_CreateDev first in the VI module.

### AK_MPI_VI_GetFrame

&emsp;&emsp;【Description】

&emsp;&emsp;Gets a VI RAW data image. Use with the channel's User mode.

&emsp;&emsp;【Syntax】

```c
 AK_S32 AK_MPI_VI_GetFrame(AK_S32 s32DevId, AK_S32 s32ChnId, VI_FRAME_INFO_S                                             *pstFrameInfo, AK_S32 s32MilliSec);
```

&emsp;&emsp;【Parameters】

| **Parameter** | **Description** | Value range | **Input/Output** |
| ------------ | ------------------------------------------ | ------ | --------- |
| s32DevId     | Device ID                                       | [0-3]  | Input        |
| s32ChnId     | Channel ID                                       | Currently only 0 | Input        |
| pstFrameInfo | Pointer to a VI frame-information structure | - | Output |
| s32MilliSec | -1: block indefinitely; 0: nonblocking; >0: wait duration in milliseconds, returning on timeout. | >=-1 | Input |

&emsp;&emsp;【Return Value】

| **Return value** | **Description**     |
| ------- | ---------- |
| 0       | Success         |
| Nonzero      | Failure; the value is an error code. |

&emsp;&emsp;【Error Code List】

| **Error code**                          | **Description**    |
| -------------------------------- | --------- |
| ERROR_VI_INVALID_CHNID           | Unsupported channel number    |
| ERROR_TYPE_INVALID_ARG | Null frame pointer |
| ERROR_VI_CHANNEL_NOT_EXIST       | Channel does not exist     |
| ERROR_VI_CHANNEL_DEVICE_NOT_OPEN | Device for this channel is not open |
| ERROR_VI_DEV_NOT_ENABLE          | Device not enabled     |
| ERROR_VI_CHANNEL_NOT_ENABLE      | Channel not enabled     |

&emsp;&emsp;【Requirements】

&emsp;&emsp;Library: libplat_vi.so

&emsp;&emsp;Header: ak_vi.h

```c
    AK_MPI_VI_CreateDev(s32DevId, &stViDevAttr);
    AK_MPI_VI_SetChnAttr(s32DevId, s32ChnId, &stViChnAttr);

    }
    AK_MPI_VI_DisableChn(s32DevId, s32ChnId);
    AK_MPI_VI_DisableDev(s32DevId);
    AK_MPI_VI_DestroyDev(s32DevId);
```
