# About This Document

&emsp;&emsp;This document is intended for programmers who use the multimedia-processing middleware. It provides reference information for the multimedia-processing software development kit during development, including APIs, header files, and error codes.

&emsp;&emsp;This document describes how to use each API provided by the multimedia-processing middleware, together with the associated data structures and error codes.
