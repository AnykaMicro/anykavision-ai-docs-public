# AnykaVision AI Documentation

AnykaVision AI is a development platform for AI camera glasses built on the KM02G series and AK1090 series chips. This documentation covers getting started, software development, hardware development and frequently asked questions.

```{note}
The English documentation has been translated from the supplied Chinese source for release 1.0.0. Genuine source gaps, including figures awaiting an original redraw and material awaiting authorization or a source rewrite, remain explicitly marked. English publication still requires the designated review gate.
```
